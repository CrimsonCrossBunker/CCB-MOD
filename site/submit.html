申请收录你的 MOD

源码留在你的仓库；CCB-MOD 只登记信息，由你继续维护。

  1. 填写资料，生成登记文件。不会上传或执行你的 MOD。
  2. 打开 GitHub 申请草稿，补充测试记录，登录后自己点击提交。申请内容是公开的。
  3. 维护者人工审核、合入并部署后，网站和启动器同时收录。申请不等于通过审核。

不熟悉版本或适配信息可先提交普通 Issue 请维护者帮助；不要猜作者或伪造测试结果。下载包应只包含一个 MOD，main.lua 或 modinfo.json 放在 ZIP 根目录或一层目录内。

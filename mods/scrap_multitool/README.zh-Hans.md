# 废料多用工具

可制作的开局工具，具备切割、锤击和撬动品质。用于实际游玩的 Lua 小示例，不是大型内容包。

## 怎么玩

新世界启用后，每个新角色获得一把废料多用工具（装不下时检查脚边）。查看工具品质或使用它；用两份废料和一块石头可再制作一把。

游戏物品 ID：`ccb_scrap_multitool`；MOD ID：`scrap_multitool`。
基线：`0.Ag-Candidate-2026-09-05-0219`，Lua API 1。

这是 CCB 仓库维护的原创教学小 MOD，不是第三方民间作品。可与其他本仓库示例一起启用。

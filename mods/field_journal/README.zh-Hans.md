# 野外观察手册

可交互的手册：查看当地天气、记录观察次数，角色记录随存档保存和恢复。

## 怎么玩

新世界启用后获得手册，使用它选择“记录观察”或“查看天气”。保存重载后记录次数仍在。可用一张纸制作替代手册。

游戏物品 ID：`ccb_field_journal`；MOD ID：`field_journal`。
基线：`0.Ag-Candidate-2026-09-05-0219`，Lua API 1。

这是 CCB 仓库维护的原创教学小 MOD，不是第三方民间作品。可与其他本仓库示例一起启用。
游戏内文字暂用简中 / 英文并列，不依赖尚未确认的外部 MOD 翻译加载机制。
请在新测试世界使用；不要从重要存档移除新增物品的 MOD。作者可参考源码开发自己的玩法。

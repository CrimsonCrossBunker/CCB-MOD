# 口袋提醒器

可重复使用的十回合提醒器，展示物品交互、角色持久化任务和重复预约防护。

## 怎么玩

新世界启用后获得提醒器。使用后让游戏经过十回合，会响一条提示；等待时重复使用不会重复预约。可用一份废料和一块石头制作。

游戏物品 ID：`ccb_pocket_alarm`；MOD ID：`pocket_alarm`。
基线：`0.Ag-Candidate-2026-09-05-0219`，Lua API 1。

这是 CCB 仓库维护的原创教学小 MOD，不是第三方民间作品。可与其他本仓库示例一起启用。
